# BlueRock Capacity Planning Dashboard

An internal capacity planning and forecasting dashboard integrating Jira and Clockify data via API.

## Features
- Real-time aggregation of logged time and remaining estimates.
- Automated workload bottleneck detection.
- Interactive visualization using Streamlit.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run data extraction scripts in the `scripts/` directory.
3. Launch the dashboard: `streamlit run app.py`
